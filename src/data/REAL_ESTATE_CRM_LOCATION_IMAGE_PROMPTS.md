# Real Estate CRM Location Image Prompts

Drop generated images under `public/images/real-estate-crm/locations/` using the **exact filenames** below.  
No code changes are needed when you add a new country or city — only add the image files that match the slug.

## Naming convention

| Type | Path |
|------|------|
| Country hero | `public/images/real-estate-crm/locations/{country-slug}/hero.webp` |
| City hero | `public/images/real-estate-crm/locations/{country-slug}/{city-slug}/hero.webp` |
| City card (optional, country page grid) | `public/images/real-estate-crm/locations/{country-slug}/{city-slug}/card.webp` |

**Format:** WebP recommended (`.webp`). Use 16:9 for hero images, 1:1 for card images.

**Style (all images):** Professional B2B SaaS marketing. Real estate CRM dashboard on a laptop or tablet. Clean, bright, trustworthy. Subtle local skyline or architecture in background. **No text overlays, no logos, no watermarks.**

## Adding a new location later

1. Add the country or city object to `src/data/realEstateCrmLocations.ts` (slug + name minimum for cities).
2. Content sections, FAQs and related links are generated automatically from the slug and region.
3. Create the image folder and drop files using the same path pattern:
   - New country `france` → `public/images/real-estate-crm/locations/france/hero.webp`
   - New city `paris` → `public/images/real-estate-crm/locations/france/paris/hero.webp`
4. Use the hero/card prompt templates above, substituting `{city}` and country name.

Until an image exists, the page shows a styled placeholder with the expected file path.
